# API Reference: ClinicCore

## Класс: `Patient`

Представляет данные пациента и методы расчёта медицинских показателей.

---

## Свойства

| Имя | Тип | Описание |
|---|---|---|
| `FullName` | `string` | Полное имя пациента |
| `BirthDate` | `DateTime` | Дата рождения |
| `Weight` | `double` | Вес в килограммах |
| `Height` | `double` | Рост в метрах |

---

## Методы

### `CalculateAge()`

Вычисляет возраст пациента.

- **Возвращает:** `int`

---

### `CalculateBMI()`

Вычисляет индекс массы тела.

**Формула:**

$$ I = \frac{m}{h^2} $$

- **Возвращает:** `double`
- **Исключения:**
  - `DivideByZeroException` — если `Height <= 0`

> [!WARNING]
> Перед вызовом метода убедитесь, что Height заполнен корректно.
